简介

OpenHuman Portable 是 OpenHuman（TinyHumans 出品，31k+ stars）的「开箱即用」便携版本。

OpenHuman 是一个基于 Tauri + CEF（Chromium Embedded Framework）的桌面级 AI 超级智能应用，拥有本地记忆、深度推理、多供应商支持等能力。

与 OpenClaw / Hermes / Claude / Codex 不同，OpenHuman 是 GUI 桌面应用，自带完整的设置界面，无需外部配置中心。

启动方式

macOS

chmod +x OpenHumanPortable.command

首次配置

1. 登录方式

启动后显示 Welcome 页面，可选择：

  • Continue Locally（实验性）— 跳过登录，直接使用本地模式
  • OAuth 登录 — Google / GitHub / X / Discord（需要网络）

2. 密钥环授权

首次启动桌面版会弹出 Keyring Consent 对话框，点击 Accept 授权本地加密存储。

3. 运行模式

模式说明推荐
CloudOpenHuman 托管一切，开箱即用推荐
Custom自选供应商，BYOK 模式进阶用户
Local实验性，跳过登录开发者
肆

配置 API Key（BYOK）

在 OpenHuman 界面中操作：

  1. 点击左下角 ⚙️ 设置（或 ⌘+, (Mac) / Ctrl+, (Win/Linux)）
  2. 进入 AI & Models
  3. 点击要启用的供应商芯片 → 粘贴 API Key → 确认
  4. 或点击 Add Custom Provider 添加自定义 OpenAI 兼容端点
推荐使用 OpenRouter 作为统一入口，一个 Key 访问所有模型。

常见问题

数据存储在哪里？

所有数据在 data/.openhuman/ 目录内。拔出 U 盘后，宿主机不留痕迹。

如何更新？

下载新版便携包，将 data/ 目录复制到新版即可保留配置和记忆。

支持哪些模型？

OpenAI、Anthropic、Google Gemini、DeepSeek、Groq、OpenRouter 等 26+ 供应商。也可以添加任何 OpenAI 兼容的自定义端点。

需要联网吗？

使用云端模型需要网络。本地模式（实验性）可以离线使用，但需要额外安装 Ollama 或 LM Studio。

macOS 提示"已损坏"？

启动器会自动执行 xattr -dr com.apple.quarantine。如果仍有问题，右键打开或在系统设置中允许。
