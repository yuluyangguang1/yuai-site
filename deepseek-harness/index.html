壹

简介

DeepSeek 开源了 AI Agent Harness —— dsh：一个「一切皆插件」的智能体框架，自带 Web UI。本项目把它打包成两种形态：

匣
便携版（推荐）
自带 Node 运行时与全部依赖的独立文件夹。解压即用，无需安装、无需管理员权限；配置与会话记录随文件夹迁移，U 盘可带走。
桌
桌面版
Tauri v2 壳：原生窗口 + 系统托盘，自动启动内置服务并打开界面。Windows 提供安装包，macOS / Linux 提供打包格式。

上游：deepseek-ai/deepseek-harness（MIT）· 本打包同样 MIT，以 yu.ai 品牌发布。

叁

快速开始

一
解压
把下载的压缩包解压到任意目录 —— 硬盘或 U 盘均可，无需安装。
二
启动
Windows 双击 dsh.bat；macOS / Linux 在终端运行：
./dsh.sh
三
使用
浏览器自动打开 http://127.0.0.1:3080，即为 dsh 的 Web UI。首次运行会在 data/ 目录初始化配置与档案，属正常的一次性步骤。
整个文件夹可以直接放在 U 盘里 —— 配置、会话、档案全部保存在 data/，插哪台电脑用哪台，拔走无痕。

桌面版：Windows 双击 setup.exe 安装即可；macOS 为免签名的 .app（压缩包），Linux 为 .deb。

肆

目录结构

dsh-portable-<platform>/
  runtime/    便携版 Node.js
  app/        dsh 本体与全部依赖
  data/       配置 / 会话 / 档案（随文件夹迁移）
  dsh.bat     Windows 启动器（双击运行）
  dsh.ps1     PowerShell 启动器
  dsh.sh      macOS / Linux 启动器
