紫微

紫微主星 · 土 · 帝王星

土 · 帝王星紫微主星

词条释义

天皇贵星，统御众星。坐命者有孤傲之气，主权威显达，天生具备领导气质。需左右辅弼配合方为完整大格。

关键词：尊贵·独立·领导

源流与名义

紫微取象于紫微垣——中天之座，众星拱而不散。斗数借以为君星，居盘而临四方，主尊贵、体面与位置，不主钱财之聚散。旧籍以其为北斗主，化气曰「尊」，义在「使人敬我」，不在「人从我」。

名义上「微」字最要紧：紫微不以外显，位在中枢而形不昭著，故古法断紫微必兼观辅佐。左右、昌曲、魁钺谓之「用印」，无辅之君谓之「孤君」，虽贵而令不行。此星先看落宫庙陷，次看四煞有无侵入，最后才论体面。

星曜属性与庙旺利陷

紫微为紫微系诸星之纲：先以五行局与生日定紫微所落之宫，本星即随之而定，故一星定位而一系皆动。站内工具注其五行为土阴。

亮度（按所落宫位地支）

  1. 庙：丑宫、午宫、未宫
  2. 旺：寅宫、卯宫、巳宫、申宫、酉宫、亥宫
  3. 得：辰宫、戌宫
  4. 平：子宫

生年四化（按出生年干）

  1. 化禄：本表无
  2. 化权：壬年
  3. 化科：乙年
  4. 化忌：本表无

本表所注亮度与站内紫微排盘同一出处；紫微无陷、无不得地之宫，其档为庙于丑午未、旺于寅卯巳申酉亥、得于辰戌、平于子。

吉凶辨析

紫微之吉在「镇」：一宫有紫微，如宅有主，煞曜来侵亦须减力，故古有「百灾不能为害」之语。然此语有前提——庙旺而有辅。若独坐、无辅、又逢空劫煞曜，则所谓帝座徒存体面，反主心高气短、任事而众不随。

吉凶之辨，全在「得辅」与「失垣」两端。得辅者，贵而能断，宜任长、宜立规；失垣者，贵而无聊，好大难成，受人奉承而不得实益。旧籍谓其「貌胜他人」，今但作自尊与标准高看，不必附会形貌。

宜忌参考

宜

  1. 任事于需名分、定规矩之位，宜居其位而言其令
  2. 会左辅右弼、文昌文曲之年月，宜立制度、带团队
  3. 处庙旺之宫，宜受聘于大组织，借其势而行己志

忌

  1. 忌无辅而独断，凡事事必躬亲则贵气化为劳碌
  2. 忌与地空、地劫同度而谈扩张，虚名易换实耗
  3. 忌以体面为决策理由——紫微之病，在不能认错

现代语境

现代语境中，紫微坐命最易验证的一点不是「贵」，而是「在意位置」：同类能力之中，此人对头衔、发言次序、被尊重的需求明显更高。以此为镜，可择宜有名分之业，避宜无名而多争之位。

又主标准感。凡审美、流程、言谈有固定尺度者，多类此。其利在可托，其弊在难协——遇不如己意者易生轻慢，此正「孤君」之现代相。

常见误解

  1. 「紫微坐命必做官、必发达」——错。紫微只主尊贵与位置，不主财与顺；无辅无禄，贵亦清寒。
  2. 「有紫微即可压煞」——半错。古法以「帝座能制煞」为通论，然皆加「庙旺有辅」之限定，独坐失垣则所谓镇压者仅存其名。
  3. 「紫微属土故宜某命人」——牵强。五行所配用于论星性之刚柔，不作年命纳音之宜忌，古书未见此用法。

关于「紫微主星」

紫微斗数以十四主星为安身立命之纲，坐守十二宫而定一生格局之骨架。星有庙旺利陷，宫有善恶吉凶，须合四化与三方四正而论，未可执一星而断全局。
