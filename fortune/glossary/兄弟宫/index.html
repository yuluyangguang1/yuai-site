兄弟宫

十二宫位 · 紫微斗数

紫微斗数十二宫位

词条释义

兄弟姐妹关系、同辈朋友、合作合伙

源流与名义

兄弟宫主同胞之恩谊，并及其同辈之间的一切往来：朋友中的至近者、合伙之伴、同门同僚之相与者，古人皆于此宫占其厚薄。其名次在命宫退一宫，与交友宫相对：一主「同源之人」，一主「外来之众」，此别最宜分明。

五行之义，同我者为比劫，八字以比劫定兄弟朋友之情，斗数以此宫当之，名目虽异而所指相近。然二法各有取象：八字看日干之生克，斗数看本宫之星情与四化，不可执彼以断此。

宫位排布与所司

本宫的排布不由人拟定，乃随命宫而定：以下四行由线上排盘引擎的安宫函数回放得出，与站内命盘同出一源。

  1. 宫序位次：自命宫退一宫（引擎自命宫顺数第十一位）
  2. 对宫（隔六位同拱）：交友宫
  3. 三方（隔四、隔八位会合）：田宅宫、疾厄宫
  4. 三方四正合宫：兄弟宫、田宅宫、疾厄宫、交友宫

读盘之序：先定命宫支位，次查本宫坐何正曜、居何庙旺，再以对宫为「外应」、三方为「会合」，四者合观方断一事之顺阻；执本宫一星而断者，未得斗数之法。

断法与吉凶辨析

本宫有吉星清曜，通说谓其同胞和顺、得力于同辈；有主星落陷兼煞曜交冲，则谓各自分张、聚少离多。若本宫无正曜，则借对宫交友之星而论，其人与兄姐之缘，每透过朋友圈、合作伙伴而显。

又一说以兄弟宫为「现金往来之地」，因对宫交友为其支出与接济之门。此属后起之用，古人但言同胞之谊；今人参之可也，执之则凿。

宜忌参考

宜

  1. 本宫清吉：宜与同辈共事、合伙，按所长分工而各得其利
  2. 对宫交友会吉：合作之缘每自朋友而来，宜从小处试起
  3. 本宫有主星得地：同胞各有专长，大事宜找其近者商量
  4. 兄弟宫为现金往来之地：账目分明则情分愈固

忌

  1. 本宫见煞而与人共产：须立据、分账，情面不代契约
  2. 以本宫吉凶断定同胞之成败得失
  3. 与同辈有金钱往来而不留凭据
  4. 以一次口角便谓兄弟宫化忌应验

现代语境

今人多以此宫看兄弟姊妹之情、合伙与团队之契，亦用以观其人与同辈相处是滋养还是消耗。

常见误解

  1. 以此宫之吉凶推及一切朋友，此当于交友宫占之。
  2. 谓兄弟宫即主兄弟人数多寡。古书虽有数目之论，皆属取象之说，今日家庭规模与古代悬殊，不宜执数。
  3. 以本宫化忌入他宫即为兄弟有损；飞化之说本言气之流动与挂碍，未可执为一事之定应。

关于「十二宫位」

十二宫如同命盘之十二衙署，各司一事：命迁主行止，财福主养，官禄主业，夫妻子女主伦常。宫以对拱三合会星，星以入垣升殿为贵，虚实相生，方见其义。
