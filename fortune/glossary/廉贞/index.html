廉贞

紫微主星 · 火 · 次桃花

火 · 次桃花紫微主星

词条释义

次桃花星，主才艺与情欲。才华出众，感情丰富，适合艺术、政界。多才多艺但需防桃花是非。

关键词：才艺·情欲·多变

源流与名义

廉取隅正，贞取守节，而此星在斗数实司两事：一曰次桃花，主情感强度与审美；二曰囚，主与规则的摩擦。属阴火，化气曰「囚」，其性外热内执。

廉贞为紫微系环布之末，宫位由紫微定位推出。论廉贞先看落宫，次看是否会煞——此星之吉凶，几乎全决于「制与不制」。

星曜属性与庙旺利陷

廉贞居紫微系第六曜，火性执而不散，故古法以此星配「囚」——有所范则为魄力，无所范则为摩擦。站内工具注其五行为火阴。

亮度（按所落宫位地支）

  1. 庙：寅宫、申宫
  2. 利：丑宫、辰宫、未宫、戌宫
  3. 平：子宫、卯宫、午宫、酉宫
  4. 陷：巳宫、亥宫

生年四化（按出生年干）

  1. 化禄：甲年
  2. 化权：本表无
  3. 化科：本表无
  4. 化忌：丙年

本表廉贞庙于寅申、利于丑辰未戌、平于子卯午酉、陷于巳亥；甲年化禄、丙年化忌，二干恰成两端，故此星最忌丙年之任意，最喜甲年之有节。

吉凶辨析

庙旺会吉，主有魄力、有魅力，宜法务、军警、公关、演艺一类以情与胆为业者。古谓「廉贞镇于庙旺，反作富贵之人」。陷地会煞，则主官非、血光、感情之累——此三者在旧籍出现最频，须以「条件成立才论」读。

吉凶之辨在「制」：与厚重之星同度或会照，谓有所范；与擎羊、陀罗、火铃同度，谓无所控。廉贞化忌最须留意，古法谓「风宪失职」，今作因小失大、因情误事看。

宜忌参考

宜

  1. 居庙旺之宫，宜与人情、欲望打交道的行业：法务、传播、医美、演艺
  2. 甲年化禄，宜以交际取财、宜出面
  3. 与厚重之星会照，宜守程序之业，其执有归

忌

  1. 忌陷地会煞而涉赌、涉色、涉讼，三事皆此星之阱
  2. 丙年化忌之年，忌情绪化签约与冲动辞受
  3. 忌以「真性情」为由不顾边界

现代语境

现代之廉贞，最好用的解释是「高强度情感＋原则感」：爱憎分明、审美有锋，容易成为焦点，也容易与规则相撞。其功课不是收敛热情，而是给热情设程序。

旧说「廉贞作桃花」，今不必限于男女：凡以个人魅力为资源之业，皆此象之用。

常见误解

  1. 「廉贞坐命必淫」——大错。桃花只主异性缘与审美感召，其应与否全在会合与自制。
  2. 「廉贞化忌必牢狱」——危言。忌主与规则摩擦，庙旺有制者不过一场口舌或一笔损失。
  3. 「廉贞属火故忌南方」——无据。星曜五行不作方位宜忌。

使用贴士

主入：命宫

关于「紫微主星」

紫微斗数以十四主星为安身立命之纲，坐守十二宫而定一生格局之骨架。星有庙旺利陷，宫有善恶吉凶，须合四化与三方四正而论，未可执一星而断全局。
