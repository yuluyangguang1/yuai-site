田宅宫

十二宫位 · 紫微斗数

紫微斗数十二宫位

词条释义

不动产、居住环境、家庭根基

源流与名义

田宅宫主不动产与居住之处，并及其家内一切器物、藏积之所，古人于此占「产业之丰歉」。位次在命宫退九宫，对宫子女：家宅与后代相拱，故传统谓家业者、所以遗其子也。

本宫又为「库」之取象：财帛言出入，田宅言收藏，故善守者重此宫。今人以之论宅、论居、论家之气氛，皆此义之延伸。

宫位排布与所司

本宫的排布不由人拟定，乃随命宫而定：以下四行由线上排盘引擎的安宫函数回放得出，与站内命盘同出一源。

  1. 宫序位次：自命宫退九宫（引擎自命宫顺数第三位）
  2. 对宫（隔六位同拱）：子女宫
  3. 三方（隔四、隔八位会合）：疾厄宫、兄弟宫
  4. 三方四正合宫：田宅宫、疾厄宫、兄弟宫、子女宫

读盘之序：先定命宫支位，次查本宫坐何正曜、居何庙旺，再以对宫为「外应」、三方为「会合」，四者合观方断一事之顺阻；执本宫一星而断者，未得斗数之法。

断法与吉凶辨析

本宫吉曜清庙，通说谓其有产业、居住环境安；太阴居之，古人谓得太阴之宅，主屋宇明洁而近水之吉；武曲、天府会之，谓库实而能守。煞曜居本宫，通说谓其处多迁动、或宅旁有嫌，非必无宅。

本宫无正曜者借对宫子女之星，其人与家宅之缘每随后代、门徒之事而动。田宅化忌入财帛者，谓其为宅而劳其财；化禄入之，谓置业顺遂而家内安。

宜忌参考

宜

  1. 本宫清庙、天府武曲会之：宜置业、宜储蓄，库实而能守
  2. 太阴在田宅：古人谓得其宅，居处宜明洁安静
  3. 本宫化禄：置业顺遂、家内安，宜早定长久之计
  4. 对宫子女会吉：家之所为，皆为后代之计，宜以布置养其习

忌

  1. 以本宫有煞便断家宅不宁；煞者多主迁动装修
  2. 以田宅独断家庭和睦，不观父母兄弟夫妻
  3. 因宫位之说而行重仓不动产
  4. 以本宫即定房舍之数目

现代语境

今人以此宫看居住之环境、置业之机与家内气氛，亦用作其安全感之参考。

常见误解

  1. 以田宅宫即定其人之房舍数目。
  2. 谓本宫有煞即家宅不宁；煞者多主变动，或为搬家、或为装修。
  3. 以此宫独断家庭和睦，而并观父母、兄弟、夫妻各宫。

关于「十二宫位」

十二宫如同命盘之十二衙署，各司一事：命迁主行止，财福主养，官禄主业，夫妻子女主伦常。宫以对拱三合会星，星以入垣升殿为贵，虚实相生，方见其义。
