交友宫

十二宫位 · 紫微斗数

紫微斗数十二宫位

词条释义

人际关系、朋友质量、社交能力

源流与名义

交友宫主其人与「非亲之人」的一切关系：朋辈、部下、门生、客户、众生之缘，古书多谓之「仆役宫」，以古人重主仆之义也。站内今从通称作交友宫，名异而宫同；线上排盘引擎保留旧名，两处所指一宫。其位在命宫所退之第七宫，对宫兄弟：一论同源，一论外缘。

本宫亦用以观其人之「群众」——其所聚者何人，为其事所能动員之力，故企业家、教师、医者尤重之。

宫位排布与所司

本宫的排布不由人拟定，乃随命宫而定：线上引擎此宫原名「仆役」，站内从今通写作「交友宫」，二名一宫。以下四行由线上排盘引擎的安宫函数回放得出，与站内命盘同出一源。

  1. 宫序位次：自命宫退七宫（引擎自命宫顺数第五位）
  2. 对宫（隔六位同拱）：兄弟宫
  3. 三方（隔四、隔八位会合）：子女宫、父母宫
  4. 三方四正合宫：交友宫、子女宫、父母宫、兄弟宫

读盘之序：先定命宫支位，次查本宫坐何正曜、居何庙旺，再以对宫为「外应」、三方为「会合」，四者合观方断一事之顺阻；执本宫一星而断者，未得斗数之法。

断法与吉凶辨析

本宫清曜得地，通说谓其多善缘、得部属之力；辅弼魁钺会之，谓于众人中有贵援。煞曜居之，通说谓其因友破财、因众生累，非谓其无友；昌曲在之谓其人以文义相交。

本宫无正曜者借对宫兄弟之星，其所与往来者常为其同辈之友、旧识之亲。以本宫化忌入财帛者，通说谓其财多耗于众；化禄入之，谓其得众之力而利其业。

宜忌参考

宜

  1. 本宫清吉、吉曜会之：宜带团队、面向众人之业，得力于众
  2. 魁钺在交友：于众人中遇贵援，宜公开场合露面
  3. 本宫化禄：得众之力而利其业，宜以分享换长久
  4. 对宫兄弟会吉：旧识同辈即为其群众之基

忌

  1. 以本宫有煞便断众人背叛；煞者多主因友耗财
  2. 以交友吉凶代兄弟而论骨肉之情
  3. 为求众缘而无边界地接济
  4. 本宫化忌入财帛仍大手支出，不知止

现代语境

今人多以此宫看团队、客户与众生缘之厚薄，亦以为其人际圈层之参考。

常见误解

  1. 以交友宫之吉凶代兄弟宫而论亲人。
  2. 谓本宫有煞即为众人背叛。
  3. 以本宫独断其人缘之好坏，而不看迁移（外境之遇）。

关于「十二宫位」

十二宫如同命盘之十二衙署，各司一事：命迁主行止，财福主养，官禄主业，夫妻子女主伦常。宫以对拱三合会星，星以入垣升殿为贵，虚实相生，方见其义。
