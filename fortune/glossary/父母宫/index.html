父母宫

十二宫位 · 紫微斗数

紫微斗数十二宫位

词条释义

父母关系、长辈缘、遗传特质

源流与名义

父母宫主其所生之亲：父母、长辈、师长、上司，以及一切「在上之缘」。位次在命宫顺一宫（即自命宫退十一宫），对宫疾厄，故古人谓父母与疾厄同线：亲遗其质，质受其疾，形气之所自来与所自病也。

古法又称此宫为「相貌宫」，以其人之形貌气质受于亲，故于此占其相貌与遗传之偏；又主文书、名分与公门之缘，契据、证照、学历之事亦隶之。

宫位排布与所司

本宫的排布不由人拟定，乃随命宫而定：以下四行由线上排盘引擎的安宫函数回放得出，与站内命盘同出一源。

  1. 宫序位次：自命宫退十一宫（引擎自命宫顺数第一位）
  2. 对宫（隔六位同拱）：疾厄宫
  3. 三方（隔四、隔八位会合）：交友宫、子女宫
  4. 三方四正合宫：父母宫、交友宫、子女宫、疾厄宫

读盘之序：先定命宫支位，次查本宫坐何正曜、居何庙旺，再以对宫为「外应」、三方为「会合」，四者合观方断一事之顺阻；执本宫一星而断者，未得斗数之法。

断法与吉凶辨析

本宫吉曜清庙，通说谓其亲有倚、长辈多援，于公门文书多得便；昌曲会之，谓以文书学业而受知于上。煞居本宫，通说谓其与上之缘多磨，或受恩而反成约束，非必其亲有损。

本宫无正曜者借对宫疾厄之星，其人与父母之关连每透过身体、家传之习而显。生年忌在此宫者，古谓「恩深反为累」，今人以之论其与上一切之牵系。

宜忌参考

宜

  1. 本宫清吉、昌曲会之：于文书、学业、公门多得便，宜循制度之路
  2. 本宫有贵曜：长辈、师长、上司为可借之源，宜近之、问之
  3. 对宫疾厄会吉：家传体质有可查，宜早告知医师
  4. 生年禄在此宫：受恩于上，宜以报答为常

忌

  1. 以本宫有煞便言父母有伤
  2. 以此宫独定容貌美丑
  3. 以父母代官禄而问上司与事业之别
  4. 受恩既深而不知节，反以依赖为缘

现代语境

今人多以此宫看与父母、上司之相处模式，以及其人与体制、文书、学业之缘分。

常见误解

  1. 以父母宫有煞即言父母有伤。
  2. 以本宫独定其人之容貌；气质之说耳。
  3. 以父母代官禄而论上司与事业之别。

关于「十二宫位」

十二宫如同命盘之十二衙署，各司一事：命迁主行止，财福主养，官禄主业，夫妻子女主伦常。宫以对拱三合会星，星以入垣升殿为贵，虚实相生，方见其义。
