疾厄宫

十二宫位 · 紫微斗数

紫微斗数十二宫位

词条释义

健康状况、体质弱点、意外灾厄

源流与名义

疾厄宫主体质之偏胜与疾病之倾向于何处，古法兼论意外之灾，故谓之「疾厄」。位次在命宫退五宫，对宫父母，因而古人以此二宫为一线：父母遗其形质，疾厄受其报应，形体之根苗皆自父母宫来。

斗数以此宫定五行偏胜之所，与中医脏腑之取象相参：木主肝胆、火主心与血脉、土主脾胃、金主肺与皮毛、水主肾与下焦。此为传统之身体观，非今日之诊断。

宫位排布与所司

本宫的排布不由人拟定，乃随命宫而定：以下四行由线上排盘引擎的安宫函数回放得出，与站内命盘同出一源。

  1. 宫序位次：自命宫退五宫（引擎自命宫顺数第七位）
  2. 对宫（隔六位同拱）：父母宫
  3. 三方（隔四、隔八位会合）：兄弟宫、田宅宫
  4. 三方四正合宫：疾厄宫、兄弟宫、田宅宫、父母宫

读盘之序：先定命宫支位，次查本宫坐何正曜、居何庙旺，再以对宫为「外应」、三方为「会合」，四者合观方断一事之顺阻；执本宫一星而断者，未得斗数之法。

断法与吉凶辨析

本宫星曜之五行与其人之所犯，通说以「偏胜」为言：火曜多则言其炎上之忧，水曜多则言其寒湿之患，金曜克木则言筋络肝胆之敏感。此皆体质倾向之说，可作调养之参考，不可作病症之判断。

本宫无正曜者借对宫父母之星，其体质多与家族之倾向相类。煞曜居之，通说谓其人多有陈年之患或外伤之迹；吉曜会之谓其病迟而来、来亦易愈。凡此皆宜就医，未可以身试占。

宜忌参考

宜

  1. 本宫星曜之五行偏胜处：作起居、饮食之节，是养生之指针
  2. 本宫清净：体质有根，老来仍安，宜保持规律
  3. 对宫父母会吉：家族之疾有其可查之处，宜早体检、早告知医师
  4. 煞在本宫：留意陈年旧患与外伤，劳形之处宜有防护

忌

  1. 以此宫之说替代医师之诊
  2. 以疾厄有煞便断必有重病
  3. 因宫位五行之说而自行服药、忌食过度
  4. 忽略后天起居，独归因于先天之宫

现代语境

今人多以此宫知其所宜防、所宜节（起居、饮食、劳形之处），以为养生之指针。

常见误解

  1. 以疾厄宫有煞即为必有重病。
  2. 以此宫替代医师之诊；站内命盘亦不作医疗建议。
  3. 以八字之病符、死符代此宫，二法名同实异。

关于「十二宫位」

十二宫如同命盘之十二衙署，各司一事：命迁主行止，财福主养，官禄主业，夫妻子女主伦常。宫以对拱三合会星，星以入垣升殿为贵，虚实相生，方见其义。
