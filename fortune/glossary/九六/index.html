九六

易理 · 结构

结构易理

词条释义

阳爻称九、阴爻称六；七八为少不变，九六为老能变，占筮以变爻为断，此爻题之由来。

关键词：老变少占

源流与名义

阳爻题「九」、阴爻题「六」，如乾初爻称初九、坤初爻称初六。此一名目取自筮数：旧说以四数为营蓍之得——六为老阴、七为少阳、八为少阴、九为老阳，九六者极数将变，故以之题爻。

要紧的一点须说清：本站六十四卦表的爻辞字段并不载爻题（64 卦共 384 条爻辞，逐条检查无一含「初九／六二」之题），题与辞是两条文献路径。故本页凡列爻题者，皆是按旧说规则由阴阳列生成，不是引古籍原文。

爻题之生成与可核边界

生成规则：位名（初、二、三、四、五、上）＋（阳爻作「九」、阴爻作「六」）。下表左列为站内卦表之六爻列，右列为按此规则所成之题。

  1. 位之名：初、二、三、四、五、上（自下而上）
  2. 爻之题：阳曰九、阴曰六（旧说，取自筮数六七八九）
  3. 站内爻辞是否含题：不含——384 条全数检查，题与辞异源
  4. 变爻之说：九六为极数故言变，七八为少故言定（旧说，站内无筮法字段）
  5. 全表按规则所成之题：九凡 192 枚、六凡 192 枚，各为 384 爻之半
  6. 站内爻辞之容量：每卦六条、共 384 条；乾、坤之「用九」「用六」别辞不在此列

按规则生成的爻题（取六卦为例）

  1. 1·乾：111111 → 初九、九二、九三、九四、九五、上九
  2. 2·坤：000000 → 初六、六二、六三、六四、六五、上六
  3. 11·泰：111000 → 初九、九二、九三、六四、六五、上六
  4. 12·否：000111 → 初六、六二、六三、九四、九五、上九
  5. 63·既济：101010 → 初九、六二、九三、六四、九五、上六
  6. 64·未济：010101 → 初六、九二、六三、九四、六五、上九

读卦先立阴阳列，再按规则补题，即可与任何一本注《易》之书对读；若某书之题与列不合（如阳爻而题六），当以列为准。

题、数、象之分

「九」「六」本是数，落在爻上才成题；由数言变（老阳变阴、老阴变阳）是筮法之推，属占之一路，不由卦画本身而来。故凡以「九六」论动静者，须先明其所据是筮法而非卦表。

站内可核者到此为止：六爻之阴阳列、位次之名、纯卦之全体（乾六阳、坤六阴）。全表按规则所成之题，九凡 192 枚、六凡 192 枚，恰各为 384 爻之半。至于「用九」「用六」两条别辞，本站卦表每卦只载六条爻辞（共 384 条，乾、坤亦然），其数不预，故凡引「用九」者属他本之文，不在本典可核之列。

题之成法还有一处不匀：初、上二位以位名在前（初九、上六），二三四五以数在前（九二、六五）。此不规则常被简化成「位前数后」而致误，本站生成爻题时即以此两条为自检（乾六题作初九、九二、九三、九四、九五、上九，坤六题作初六、六二、六三、六四、六五、上六）。

现代语境

今天读《易》，九六常被读作「阶段之名」：初九潜、九五飞之类。此读法亲切而无损，只是要认得它是题与义的嫁接。用作占卜解爻时，「变爻」一说系于筮法，本站工具之起卦与变爻口径以工具页所列为准，不与本典互推。

常见误解

  1. 「九六即是爻的编号」——编号只表序，九六表阴阳兼表将变，其义在数不在序；同位之九与六恰相反。
  2. 「爻辞本文带着九六」——站内爻辞字段不载题（384 条已全数检查），今本经文的「初九」等是整理时所加。
  3. 「凡九皆阳之盛、凡六皆阴之衰」——九为老阳、六为老阴，皆是极数；以九六分强弱者，与以九二五之「中」分强弱者，是两套说法。

关于「易理」

易理所以明易之理：元亨利贞见乾之四德，阴阳刚柔明三才之道，爻位九六定占读之法，互综错开取象之门。由辞观象、由象观占，而后知古人垂教之意。
