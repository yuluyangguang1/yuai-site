claude portable

Claude Code 便携版 + CC Switch API 代理 · 零安装 · U 盘即走

它是什么

Claude Portable 把 Anthropic 的 Claude Code CLI 和 CC Switch API 代理打包在一个文件夹里。解压、双击、开始编程。不需要安装 Node.js，不需要 npm，不需要配置 PATH。

CC Switch 让你可以用第三方 API（DeepSeek、智谱、Kimi 等兼容 Anthropic 协议的服务）驱动 Claude Code，不局限于 Anthropic 官方 API。

快速开始

1. 下载解压

从 GitHub Releases 下载最新的 ClaudeCodePortable.zip（当前最新 v0.2.0），解压到任意目录或 U 盘。

提示：保留旧版 data/ 目录覆盖到新版，配置和会话自动保留。

2. 启动

平台操作
macOS双击 ClaudePortable.command
Windows双击 ClaudePortable.bat
Linux./ClaudePortable.sh

3. 首次配置

首次启动会提示配置 API：

  • 方式 1（推荐）：选择 CC Switch 图形界面，在 GUI 中添加 Provider（支持 Anthropic / DeepSeek / 智谱 / Kimi / 自定义）
  • 方式 2：命令行输入 API 地址和 Key

配置完成后，Claude Code 自动通过 CC Switch 代理连接 API。

4. 开始使用

claude              # 交互模式
claude -p "重构这个函数"  # 一次性任务
claude -c           # 继续上次对话

自定义你的中转站地址任何兼容 Anthropic API 的服务

便携特性

  • 零安装：不需要 Node.js、npm、Python，所有依赖内置
  • 零痕迹：所有数据写在 data/ 目录，不污染系统
  • 配置随身：CC Switch 数据库自动同步到 data/cc-switch/，换机自动恢复
  • U 盘即走：整个文件夹拷到 U 盘，换电脑继续用
  • 跨平台：同一个 zip 包含 macOS (ARM/Intel) + Linux + Windows
  • 自动更新：CI 每次构建自动拉取最新 Claude Code + CC Switch 版本

macOS 权限问题

首次运行如果提示"无法验证开发者"：

cd /path/to/ClaudeCodePortable
xattr -cr .
chmod +x ClaudePortable.command

常见问题

CC Switch 启动后代理端口不通？

CC Switch 3.15.0 默认监听 15721 端口（旧版 18080）。脚本会自动从数据库读取正确端口。如果端口仍不通，检查 CC Switch 设置中的代理端口配置。

想直接用 Anthropic 官方 API？

不需要 CC Switch。设置环境变量后直接运行：

export ANTHROPIC_API_KEY="sk-ant-..."
./bin/macos-arm64/claude

如何更新 Claude Code？

下载最新的 Release zip 覆盖 bin/ 目录即可。data/ 和 config/ 不会被覆盖。
