第一次使用：四步上手

整个过程不到 2 分钟。

1
把 U 盘插到电脑

插好后打开 U 盘，找到 ClaudeCodePortable 文件夹，进入里面。

2
双击启动文件

找到对应你系统的启动文件，双击它：

  • Windows：双击 ClaudePortable.bat
  • macOS：双击 ClaudePortable.command
  • Linux：双击 ClaudePortable.sh 或在终端运行

启动后会出现一个黑色终端窗口和 YLYG logo，这是正常的。

第一次启动会自动完成绑定（绑定到你这块 U 盘），需要等几秒。

3
出现 CC Switch 窗口（如果是首次配置）

如果 U 盘是全新未配置的，会自动弹出 CC Switch 图形界面。在里面：

  • 点 "添加 Provider" 或 "+" 按钮
  • 填写 API Base URL（如 https://api.anthropic.com 或第三方端点）
  • 填写 API Key
  • 类型选 Claude
  • 点 保存（不需要关闭 CC Switch 窗口）

如果卖家已经在 U 盘里预配置了 Provider，这一步会自动跳过。

4
确认信任目录，开始对话

Claude Code 启动后会问 "Is this a project you trust?"，按 Enter 选择 "Yes, I trust this folder"。

看到 > 提示符就可以开始对话了。试着输入 "你好" 测试一下。

★
之后再用就更简单：插 U 盘 → 双击启动文件 → 直接进入 Claude Code 对话界面。

关于 U 盘绑定

这块 U 盘已经为你配置好了 API 和绑定。你可以把 U 盘插到任何电脑使用，配置都跟着 U 盘走。但出于安全考虑，文件夹被复制到其他设备运行时会被拒绝。

切换大模型 / Provider

需要换不同的 API 提供商或不同 Key 时，打开 U 盘里的 CC Switch 工具：

  • Windows：打开 U 盘 → 进入 bin\windows-x64\ 文件夹 → 双击 cc-switch.exe
  • macOS：打开 U 盘 → 进入 bin/macos-arm64/ 或 bin/macos-x64/ 文件夹 → 双击 cc-switch
  • Linux：进入 bin/linux-x64/ 文件夹 → 双击 cc-switch

在 CC Switch 图形界面里：

  • 添加新 Provider：点 "+" 或"添加"按钮，填入 Base URL 和 API Key，保存
  • 切换 Provider：在 Provider 列表中点击对应的"激活"按钮
  • 关闭 CC Switch：保存后直接关闭窗口即可

下次双击启动文件时，Claude Code 会自动使用你激活的 Provider。不需要重新配置任何东西。

💡
小贴士：CC Switch 可以同时保存多个 Provider，比如 Anthropic 官方、MiniMax、DeepSeek 等。你随时一键切换，不用重新输 API Key。

常见问题

启动后说 "No provider found"

这种情况很少出现。如果遇到，先重新插拔 U 盘再双击启动文件。如果仍然有问题，联系卖家。

macOS 提示 "无法验证开发者" 或 "无权限执行"

第一次双击 .command 文件可能提示无法执行。两种处理方式：

  • 右键打开（推荐）：右键点击 ClaudePortable.command → 选择"打开" → 在弹窗中再点"打开"。下次就能双击运行了。
  • 用终端：打开"终端"，输入 chmod +x （带空格），把 ClaudePortable.command 文件拖到终端里，回车即可。同样处理一遍 lib/binding.sh。

这是 macOS 自带解压工具的限制 — 解压 zip 时会丢失文件的执行权限。用 The Unarchiver 或 Keka 解压可以避免此问题。

Windows 上首次运行报错或卡住

常见原因：

  • U 盘格式问题：联系卖家更换
  • 杀毒软件拦截 mklink 命令：临时关闭杀毒软件

"Auth conflict" 警告

如果之前自己装过 Claude Code，环境变量可能冲突。脚本启动时会自动清理。如果还有问题，关闭所有终端重新双击启动文件。

双击没反应（Linux）

大部分 Linux 文件管理器默认不会双击执行 .sh。打开终端：

cd /path/to/ClaudeCodePortable
chmod +x ClaudePortable.sh
./ClaudePortable.sh
