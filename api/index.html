API 代理

统一接口，一处配置，所有项目共用。

第一步 · 获取 Key

前往 b.ai 注册账号，在后台生成你的 API Key。支持多种模型（DeepSeek、OpenAI、Claude 等），按量计费。

前往 b.ai 注册 →
第二步 · 配置项目

在你的项目中将 baseURL 指向我们的统一入口：

Base URL
https://api.yuai-r.cn/v1

API Key 填写你在 b.ai 获取的 Key 即可。

第三步 · 开始使用

配置完成后，你的项目即可通过 yu.ai 的统一接口访问多种 AI 模型。换模型、换线路只需在 b.ai 后台操作，项目端无需任何改动。

支持的模型

通过 b.ai 中转，支持但不限于：

  • DeepSeek V3 / R1
  • OpenAI GPT-4o / o3 / o4-mini
  • Claude Sonnet / Opus
  • Gemini 系列
  • Qwen / 通义千问系列

完整列表见 b.ai 模型页。

统一的好处

  • 一处 Key，所有项目共用 — 织文、Linger、你的其他工具指向同一个 baseURL
  • 换模型不改代码 — 在 b.ai 后台切换模型，项目端只需改 model 名称
  • 用量透明 — b.ai 后台有完整的消费记录
