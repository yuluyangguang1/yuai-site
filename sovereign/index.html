三个承诺
01 数据零外传 所有对话历史、API Key、记忆库、技能配置只写到 U 盘的 ./data/ 目录。除你显式选择的模型 API 调用外，没有任何对外网络请求。配套审计工具 openclaw audit 一键导出网络出站清单。
02 主机零残留 不写入 Windows 注册表、不创建 macOS LaunchAgent、不污染 PATH。拔下 U 盘，主机回到使用前状态，毫无痕迹。员工借用同事电脑、出差用酒店机器、敏感场景用一次性主机，全部安全。
03 国产模型优先 默认推荐 DeepSeek、智谱 GLM、通义千问、Kimi 等国产 SOTA 模型，全部使用 OpenAI 兼容协议。可一键关闭所有海外厂商，让 AI 对话只走境内 API。配套主权部署版可对接私有化大模型 (vLLM / 火山方舟私有部署 / 阿里百炼专属)。
应用场景
企业 / 制造业
员工本地 AI 助手
市场部、设计部、研发部都想用 AI，但合规怕泄密。员工人手一个 U 盘，预装 OpenClaw + 已签内部审批的模型 Key，本地处理所有商业文档。IT 部门审计：导出每个 U 盘的网络出站日志即可。
高校 / 实验室
学生统一 AI 工具包
每位学生新生入学发一个 U 盘，预装 Hermes + 智谱 GLM 学术免费版 Key，开学第一天双击即用。论文查重、外文翻译、代码辅助、ppt 起草，无需任何额外配置。学校付费模式：每年一次硬件更换 + key 续费。
政务 / 公务系统
敏感数据本地处理
公文起草、政策研究、舆情分析、便民问答机器人。数据不出内网，模型 API 走政务专线对接的国产私有化大模型。开源代码可审计，可定制部署到内网任意一台 Windows / 麒麟 / 银河 OS 终端。
医疗 / 医院
病例与文献本地分析
电子病历、影像报告、文献综述、患者沟通脚本。所有 PHI（受保护健康信息）只在医生工作站本地处理，不上传任何云端。可对接医院私有部署的医疗大模型，或使用经过等保三级认证的国产 API。
法律 / 律所
案件资料 AI 检索
合同审查、法条对比、判例检索、客户沟通模板。律师电脑插上 U 盘，所有客户资料只在本地分析，对接对应国产模型即可。律所可配置只允许特定模型供应商，实现律师执业保密义务的技术保障。
SaaS / 软件公司
开发者本地 AI 编程
替代 Cursor / Claude Code / Cline 的本地化方案，模型可换 DeepSeek-V4-Pro / Kimi K2.6 / GLM-4.7 等国产 coding 模型。代码不上传海外服务，源码安全合规。技能系统支持团队共享 prompt 模板，避免重复造轮子。
