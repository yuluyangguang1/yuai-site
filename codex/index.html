启动方式

平台启动器
macOS双击 CodexPortable.command
Windows双击 CodexPortable.bat
Linux./CodexPortable.sh

首次运行 CC Switch GUI 自动打开，在 Codex 标签添加供应商保存 → Codex CLI 启动。

贰

API 配置

Codex CLI 通过两个文件管理配置：

  • data/.codex/auth.json — API Key
  • data/.codex/config.toml — 模型供应商定义

CC Switch 自动配置

启动后 CC Switch 切换到 Codex 标签，选择模板：

  • OpenAI 官方
  • 第三方中转（one-api / new-api / 等）
  • DeepSeek / Kimi / GLM 等国产模型
  • Azure OpenAI

手动配置示例

{"OPENAI_API_KEY": "sk-..."}
model_provider = "custom"
model = "gpt-5.4"
model_reasoning_effort = "high"

[model_providers.custom]
name = "Custom"
base_url = "https://your-provider/v1"
wire_api = "responses"
env_key = "OPENAI_API_KEY"
叁

设备绑定

首次成功运行后，便携包绑定到当前 U 盘的文件系统 UUID。复制到其他设备运行将报错。

解绑命令

# macOS
./CodexPortable.command --unlock

# Linux
./CodexPortable.sh --unlock

# Windows
CodexPortable.bat --unlock
💡 双 lock 文件镜像，删除单个不能绕过绑定
肆

Codex CLI 命令

命令说明
codex进入交互式对话
codex "任务描述"执行一次性任务
codex --approval-mode suggest仅建议，不自动执行（默认）
codex --approval-mode auto-edit自动编辑文件，执行命令需确认
codex --approval-mode full-auto全自动执行（慎用）
codex --model <模型名>指定使用的模型
codex --quiet安静模式，减少输出

wire_api 说明：Codex v0.136+ 已移除 chat 模式，统一使用 wire_api = "responses"。CC Switch 会自动处理。

macOS 权限问题

首次运行如果提示"无法验证开发者"：

cd /path/to/codex-portable
xattr -cr .
chmod +x CodexPortable.command

或右键 → 打开 → 弹窗中确认。只需一次。

柒

常见问题

CC Switch 打不开？

确保系统有 Python 3。配置中心默认监听 17590 端口。Python 不可用时会回退到 cc-switch GUI 二进制。

想直接用 OpenAI 官方 API？

export OPENAI_API_KEY="sk-..."
./bin/macos-arm64/codex

如何更新？

下载最新 Release zip 覆盖 bin/ 目录即可。data/ 不会被覆盖。
