关于

OpenClaw Portable 是基于 OpenClaw（开源 AI 助手框架）的便携版发行包。自带 Node.js 运行时，双击即可在 Windows / macOS / Linux 上启动，无需安装任何依赖。

·
便携的含义 — 所有数据（API Key、对话历史、配置）都存在 U 盘上。插上 U 盘就能用，拔掉 U 盘什么都不留。

快速开始

从 下载 zip，解压到 U 盘或任意目录。

Windows双击 OpenClaw.vbs
macOS双击 OpenClaw.app
Linux双击 OpenClaw.desktop

首次使用流程

1
等待初始化

首次启动需要 10-30 秒加载运行时。

2
配置模型

浏览器自动打开配置中心。选择 AI 平台，填写 API Key。推荐 DeepSeek（国内直连）或 OpenRouter（多模型聚合）。

3
开始对话

保存配置后点击「打开聊天」，进入 http://127.0.0.1:18789 对话界面。

i
端口说明
配置中心 18750聊天界面 18789
所有服务仅监听 127.0.0.1，外部无法访问。

macOS 首次启动

macOS 可能提示「无法验证开发者」。解决方法：

  • 右键点击 OpenClaw.app → 选择「打开」→ 弹窗中点「打开」
  • 或终端执行：xattr -cr /path/to/OpenClawPortable
  • 或系统设置 → 隐私与安全性 → 底部点「仍要打开」

手机连接

让同一 WiFi 下的手机连接到 OpenClaw Gateway，无需在手机上安装任何东西。

启动方式

平台启动器
macOSsystem/Mac-Mobile.command
Linuxsystem/Linux-Mobile.sh
Windowssystem/Windows-Mobile.bat

双击启动器，以 LAN 模式临时启动 Gateway。退出后自动恢复原始配置。

连接方式

  • 手机浏览器（推荐）— 打开 http://电脑局域网IP:端口，Android / iOS 均可
  • 官方 App — 编译 openclaw 仓库的 apps/android 或 apps/ios
  • 第三方 App — andClaw / AnyClaw / FlutterClaw，手动输入 WebSocket 地址

也可以在配置中心 Web UI 中直接开启手机连接模式。
