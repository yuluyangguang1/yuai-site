快速上手

五步启动你的 OpenClaw Portable

  1. 解压到 U 盘或任意目录
  2. macOS: 双击 OpenClaw.app / Windows: 双击 OpenClaw.vbs
  3. 浏览器打开配置中心 http://127.0.0.1:18750
  4. 选择模型平台 → 填入 API Key → 保存
  5. 点击「打开聊天界面」开始对话

常见问题

来自「扫盲版」文档的高频问题解答

上下文超限 (400 Total tokens exceed)
输入 /new 开启新对话清空上下文，或升级模型套餐以获得更大的上下文窗口。
飞书多 agent 配置
建议先配置一个 agent 跑通全流程，熟悉之后再逐步添加多个。不要一上来就配多个，容易混乱。
机器人没有消息输入框
检查三项配置：应用权限是否开启、回调事件是否正确注册、长链接配置是否生效。
API 限速 (Rate Limit)
等待当前周期刷新即可恢复，或升级套餐提升调用频率上限。
防止 Mac 休眠
使用 caffeinate -i 命令保持唤醒。但不建议将 Mac 作为长期服务器使用，稳定性和散热都不理想。
编程工具集成
参考知乎专栏 (zhuanlan.zhihu.com) 上的集成方案，可将 OpenClaw 与 VS Code、Cursor 等编辑器联动。
