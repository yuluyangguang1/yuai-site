快速上手

五步启动你的 OpenClaw Portable

  1. 解压到 U 盘或任意目录
  2. macOS: 双击 OpenClaw.app / Windows: 双击 OpenClaw.vbs
  3. 浏览器打开配置中心 http://127.0.0.1:18750
  4. 选择模型平台 → 填入 API Key → 保存
  5. 点击「打开聊天界面」开始对话

常见问题

来自「扫盲版」文档的高频问题解答

上下文超限 (400 Total tokens exceed)
输入 /new 开启新对话清空上下文，或升级模型套餐以获得更大的上下文窗口。
飞书多 agent 配置
建议先配置一个 agent 跑通全流程，熟悉之后再逐步添加多个。不要一上来就配多个，容易混乱。
机器人没有消息输入框
检查三项配置：应用权限是否开启、回调事件是否正确注册、长链接配置是否生效。
API 限速 (Rate Limit)
等待当前周期刷新即可恢复，或升级套餐提升调用频率上限。
防止 Mac 休眠
使用 caffeinate -i 命令保持唤醒。但不建议将 Mac 作为长期服务器使用，稳定性和散热都不理想。
编程工具集成
参考知乎专栏 (zhuanlan.zhihu.com) 上的集成方案，可将 OpenClaw 与 VS Code、Cursor 等编辑器联动。

渠道对接

把 OpenClaw 接入你常用的聊天平台

飞书

步骤概览：创建飞书应用 → 添加机器人能力 → 开通权限 → 配置事件回调（长连接）→ 在 OpenClaw 填入 App ID + App Secret → 重启 Gateway

关键权限：im:message:send_as_bot、im:message.p2p_msg:readonly、im:message.group_at_msg:readonly、im:resource

事件订阅：添加 im.message.receive_v1，使用长连接模式（不需要公网 IP）

飞书开放平台：open.feishu.cn/app

微信

方案 1：微信 ClawBot 插件（官方，2026.3 推出）— 在微信设置中启用 ClawBot 插件，绑定 OpenClaw 实例即可。

方案 2：iLink 扫码登录（OpenClaw Portable 内置）— 配置中心点击"微信登录"，手机扫码授权，无需公众号开发者资质。

方案 3：企业微信应用 — 创建企业微信自建应用，配置回调 URL，适合团队使用。

Telegram

步骤：@BotFather 创建 Bot → 获取 Token → 在 OpenClaw 配置中填入 Token → 重启 Gateway

注意：国内网络需要代理才能连接 Telegram API。可在配置中设置 HTTPS_PROXY 环境变量。

QQ

步骤：QQ 开放平台注册 → 创建机器人应用 → 获取 AppID + Token → 在 OpenClaw 配置中填入 → 用 QQ 扫码加机器人好友 → 重启 Gateway

QQ 开放平台：q.qq.com

Discord

步骤：Discord Developer Portal 创建 Application → 添加 Bot → 获取 Token → 开启 Message Content Intent → 邀请 Bot 到服务器 → 在 OpenClaw 填入 Token → 重启

Developer Portal：discord.com/developers

其他平台

OpenClaw 还支持：Slack、WhatsApp、Signal、LINE、Google Chat、MS Teams、钉钉。配置方式类似：在对应平台创建 Bot/App → 获取凭证 → 填入 OpenClaw 配置 → 重启 Gateway。

所有渠道配置都可以在配置中心 Web UI 中完成，无需手动编辑 JSON。

Skill 开发入门

从零开始写一个自定义技能

什么是 Skill

Skill 是一个 Markdown 文件（SKILL.md），用自然语言告诉 AI 在什么场景下做什么事。不需要写代码，不需要训练模型。

最小 Skill 示例

---
name: daily-summary
description: 每天总结今日完成的任务
trigger: 当用户说"今日总结"或"日报"时触发
---

# 行为规则

1. 回顾今天的对话记录
2. 提取所有已完成的任务
3. 按时间顺序整理成简洁的日报格式
4. 如果没有任务记录，友好提示用户

安装自定义 Skill

把 SKILL.md 放到 ~/.openclaw/skills/daily-summary/SKILL.md，重启 Gateway 即可生效。

或者从 GitHub 安装：

clawhub install your-github-username/your-skill-repo

进阶：带工具的 Skill

Skill 可以声明需要的环境变量、依赖的二进制工具：

---
name: weather-report
description: 查询天气并生成播报
metadata:
  openclaw:
    requires:
      env:
        - WEATHER_API_KEY
      bins:
        - curl
    primaryEnv: WEATHER_API_KEY
---

# 行为规则
1. 调用天气 API 获取用户所在城市的天气
2. 生成简洁的天气播报
3. 如果 API Key 未配置，提示用户设置

发布到 ClawHub

写好 Skill 后可以发布到社区：

clawhub login
clawhub skill publish ./my-skill/

成本控制

省 Token、选对模型、控制开销

模型性价比推荐（2026 年）

日常对话DeepSeek-V4-Chat（便宜、中文好）
复杂推理DeepSeek-V4-Pro / Kimi K2.6（思考模式）
编程辅助DeepSeek-Coder / Claude Sonnet
免费体验智谱 GLM-4-Flash（免费额度）/ 通义千问（免费层）
完全离线Ollama + Qwen2.5-7B / DeepSeek-R1-8B

省 Token 技巧

  • 安装 openclaw-token-optimizer 技能，自动压缩上下文
  • 对话过长时输入 /new 开启新会话，避免上下文累积
  • 配置 models.fast 为轻量模型（如 Mistral-7B），简单任务自动走快速模型
  • 关闭不需要的 Skill（每个活跃 Skill 都会占用系统提示词 Token）
  • 使用本地模型处理隐私数据，云端模型处理需要联网的任务

监控用量

在配置中心可以查看 Token 消耗统计。也可以在模型提供商的控制台查看 API 调用量和费用：

  • DeepSeek：platform.deepseek.com
  • 智谱：open.bigmodel.cn
  • 通义千问：dashscope.console.aliyun.com
